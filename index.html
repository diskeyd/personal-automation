개인용 명령줄 자동화 도구 · 운영자 본인 계정 전용

무엇인가

운영자 본인이 자신의 학습 기록과 개인 자료를 정리하기 위해 만든 명령줄 도구입니다. 운영자의 개인 기기에서만 실행되며, 일반에 배포하거나 제3자에게 서비스를 제공하지 않습니다. 서버를 운영하지 않고 계정도 하나만 사용합니다.

무엇을 하는가

  • 강의 녹음 파일을 전사한 뒤 Google Drive에 보관
  • 일정과 마감을 Google Calendar에서 조회·등록
  • 메일에서 필요한 공지·안내를 찾아 읽기 (읽기 전용)
  • 정리한 결과를 Google Docs · Sheets로 기록

사용하는 Google 권한

Gmail(읽기 전용) · Calendar · Drive · Docs · Sheets. 사용자가 동의 화면에서 직접 승인한 범위에만 접근하며, 인증 토큰은 운영자 기기의 로컬 설정 디렉터리에만 저장됩니다.
